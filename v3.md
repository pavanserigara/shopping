## New color theme — yellow and white
Replace the previous color tokens platform-wide with a **yellow and white** theme. Apply as CSS variables/design tokens, used consistently across every page — do not hardcode colors per page.

- **Background**: white / off-white (`#FFFFFF` / `#FFFDF7`) — keep it clean and bright, not cream-heavy.
- **Primary/brand yellow**: a confident, saturated yellow for headers, active states, and key brand moments (e.g. `#F5B400` / `#F2A900` range) — not a pale pastel yellow, it needs enough contrast to look intentional, not washed out.
- **CTA/action color**: a darker amber or deep yellow-orange for buttons like "Add to cart" and "Order via WhatsApp" (e.g. `#D97F00` range) so buttons are clearly clickable and pass contrast checks against white.
- **Text**: dark charcoal (not pure black) for body text on white backgrounds — never place body text directly on the bright yellow without checking contrast; use dark charcoal text on yellow backgrounds, not white text on yellow.
- **Borders/dividers**: light warm gray, not black, to keep the theme feeling bright and cohesive.
- **Status badges** (order statuses, stock status, etc.): keep semantic colors (green = success/completed, red = out of stock/error, blue = info) as accents against the yellow/white base — don't force every UI element into yellow, use yellow for brand and structure, semantic colors for status meaning.
- Run a contrast check on every text-on-color combination before finalizing — yellow backgrounds are notorious for failing contrast with the wrong text color.
- Remove the previous dark theme entirely for now — ship one clean, finished light (yellow/white) theme rather than two half-finished ones.

## Storefront redesign
Rebuild the storefront's visual design on the new theme, keeping all existing functionality (product grid, cart, WhatsApp ordering, product gallery, ads from v2) — this is a visual and responsiveness fix, not a feature rebuild.

- Re-check every section against the new palette: header, category tabs, product cards, product detail view, cart drawer, banner/mid-page ads.
- **Mobile specifically** (this was called out as broken — fix thoroughly, test at 375px width):
  - Header must not overflow or wrap awkwardly — collapse search into an icon that expands on tap if needed.
  - Product grid must be a clean 2-column layout on mobile with readable text at that card size — no cramped or overlapping text.
  - Cart drawer must be full-screen or full-width on mobile, not a squeezed sidebar.
  - Buttons and tap targets must be large enough for touch (minimum ~44px height).
  - Images must not cause horizontal scroll — constrain everything to viewport width.
- Re-verify at tablet (~768px) and desktop (~1280px+) after mobile is fixed, so nothing regresses going up in screen size.
