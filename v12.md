# Upgrade Prompt & Pass Summary (v12) — LocalShopOS: Branded QR Studio, Subscription Gating, Dynamic Pricing & Admin Search Controls

Documenting Pass 12 enhancements for LocalShopOS. This pass upgrades the QR Code feature into a multi-theme studio, expands subscription plan feature gating, synchronizes the landing page pricing matrix dynamically, introduces centralized super admin contact management, and adds live search capabilities for tenant plan upgrades.

---

## Part A: Branded QR Code Studio & Print Standee Generator (`dashboard/share.php`)

Upgraded the shop QR generator into an interactive, studio-quality workbench with offline reliability and print-ready options.

- **Local Library Offline Bundling**: Downloaded and stored `/assets/js/qrcode.min.js` locally to guarantee 100% scannable QR generation without relying on external CDNs or active internet connectivity.
- **4 Live Interactive Visual Themes**:
  - 👑 **Gold Luxury**: Obsidian Navy (`#0F172A`) backdrop with metallic gold (`#F5B400`) corner finders and verified merchant header badge.
  - 💚 **WhatsApp Green**: Vibrant Emerald Green (`#059669`) canvas optimized for WhatsApp catalog sharing.
  - 🌑 **Obsidian Dark**: High-contrast dark mode canvas with crisp monochrome finders (`#18181B`).
  - ⚪ **Minimal Retail**: Crisp white design suited for standard thermal or inkjet desktop printing.
- **Dynamic Shop Branding Embed**: Encodes shop logo or initial badge inside a gold-ringed central circle on the 1000x1000px high-resolution canvas.
- **🖨️ Counter Standee Print View**: Added a print mode styled for A4/A5 tabletop acrylic desk stands (`window.print()`).
- **High-Resolution PNG Download & Native Share**: Instant 1000x1000px PNG image download and Web Share API integration.

---

## Part B: Subscription Plan Feature-Gating Expansion (`includes/features.php`)

Gated key platform features behind subscription tiers controlled by Super Admin.

- **New Feature Registry Keys**:
  - `qr_code_generator`: Branded QR Code Studio & Print Standees.
  - `coupons`: Discount Coupons & Promo Code Creator.
- **Dashboard Feature Access Control**:
  - Enforced `tenant_has_feature()` checks at top of `dashboard/share.php` and `dashboard/coupons.php`.
  - Displays standardized locked feature notice (`render_locked_feature_notice()`) with upgrade call-to-action for unauthorized tiers.
  - Added dynamic 🔒 lock indicators to desktop header navigation links and mobile drawer items for locked features.
- **Super Admin Plan Builder Integration**: Admin plan management (`admin/plans.php`) automatically lists `qr_code_generator` and `coupons` in the feature checklist.

---

## Part C: Fully Dynamic Landing Page Pricing Matrix (`index.php`)

Synchronized the public landing page pricing section with real-time database subscription plans.

- **Dynamic Comparison Matrix**: Renders all 10 feature keys from `FEATURE_REGISTRY` with `✓` (included) or `✗` (excluded) status per plan card.
- **Automated Badging**: Automatically highlights recommended mid-tier plans with a "★ Most Popular" badge and flags free/default plans.
- **Live Limits & Pricing**: Renders price (`₹/month`), billing period, and product limits dynamically from MySQL `plans` and `plan_features` tables.

---

## Part D: Centralized Super Admin WhatsApp Contact & Settings (`admin/settings.php`)

Centralized support and plan upgrade contact routing under Super Admin control.

- **New Setting (`whatsapp_contact`)**: Super admin can configure the platform's WhatsApp support/upgrade phone number (with country code, e.g. `919876543210`).
- **Dynamic Upgrade CTAs**: Merchant dashboard upgrade links (`dashboard/plans.php`) automatically direct merchants to the admin's WhatsApp number with pre-filled upgrade text (`"Hello LocalShopOS! I would like to upgrade my shop..."`).

---

## Part E: Instant Tenant Live Search Bar (`admin/index.php`)

Streamlined Super Admin tenant management and plan updates.

- **Live Client-Side Filter**: Search input positioned directly above the **Registered Tenants & Health Monitoring** table.
- **Multi-Field Matching**: Filters tenant rows in real-time by **Shop Name**, **Subdomain**, or **WhatsApp Contact Number** without page reloads.
- **Live Counter & Reset**: Displays matching store count (e.g. `2 of 5 Tenants`) with a one-click `✕` search reset button.
